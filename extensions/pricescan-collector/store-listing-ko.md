# PriceScan - 네이버 현재 화면 가격 가져오기

## 짧은 설명

네이버 쇼핑에서 사용자가 확인한 현재 화면의 상품 가격을 최대 10개까지 PriceScan으로 가져옵니다.

## 상세 설명

PriceScan은 판매자가 경쟁 가격을 비교하고 마진을 판단하기 쉽게 돕는 도구입니다.

사용자가 Chrome에서 네이버 쇼핑 검색 결과를 직접 확인하고 확장 프로그램 버튼을 누르면, 현재 화면에 이미 표시된 상품명·가격·판매처·배송비·상품 링크를 최대 10개까지 PriceScan으로 가져옵니다.

자동 검색, 자동 스크롤, 자동 클릭, 반복 요청, CAPTCHA 우회는 하지 않습니다. 로그인 정보·비밀번호·쿠키·결제정보도 읽거나 전송하지 않습니다.

## 카테고리

쇼핑

## 단일 목적

사용자가 직접 확인한 네이버 쇼핑 현재 화면의 가격 비교 항목을 PriceScan 웹앱으로 가져오는 기능만 제공합니다.
