# PriceScan - AI 감독형 가격 조사

## 짧은 설명

검색 한 번으로 사전 로그인된 네 쇼핑몰의 현재 화면 최저가 후보를 조사해 PriceScan으로 가져옵니다.

## 상세 설명

PriceScan은 판매자가 경쟁 가격을 비교하고 마진을 판단하기 쉽게 돕는 도구입니다.

PriceScan에서 검색어를 한 번 입력하면 네이버·다나와·에누리·쿠팡을 한 전용 탭에서 차례로 열고, 현재 로드된 후보 최대 10개를 배송비 포함 가격으로 비교합니다. 쇼핑몰별 가장 낮은 유효 후보 한 개의 상품명·가격·판매처·배송비·상품 링크를 확인해 내 판매상품에 연결합니다. 처음 사용할 때만 선택한 쇼핑몰 접근 권한을 한 번 허용합니다.

로그인 만료, CAPTCHA·보안 확인, 접근 제한, 가격·배송비 판독 불확실 상태에서는 자동 진행과 재시도를 멈추고 사용자 확인을 요청합니다. 로그인 정보·비밀번호·쿠키·결제정보는 읽거나 전송하지 않습니다. 자동 스크롤이나 CAPTCHA 우회도 하지 않습니다. 현재 화면에 로드된 후보를 비교하므로 전체 쇼핑몰의 절대 최저가를 보장하는 서비스는 아닙니다.
