# PriceScan Chrome Extension

PriceScan에서 상품명을 한 번 입력하면 로그인된 네이버·다나와·에누리·쿠팡 화면을 차례로 열고, 서버 AI가 현재 화면의 최저가 후보를 판독하는 최소 권한 실행부입니다.

## 사용 방법

1. Chrome에서 필요한 쇼핑몰에 미리 로그인합니다.
2. PriceScan을 열고 상품명을 입력한 뒤 `AI 최저가 찾기`를 누릅니다.
3. 처음 한 번 쇼핑몰 화면 접근을 허용합니다.
4. 로그인 만료·캡차·보안 확인 알림이 올 때만 직접 처리하고 이어서 진행합니다.
5. 조사가 끝나면 PriceScan 표에서 원본 링크와 가격을 확인합니다.

확장 프로그램은 서버가 배포한 허용 목록 안에서 검색·공개 상품 링크 이동만 수행합니다. CAPTCHA를 풀거나 우회하지 않고, 로그인·보안 확인·판독 불확실 상태에서 멈춥니다. 기존 고정 파서는 새 AI 검색의 대체 경로로 사용하지 않습니다.

## 권한

- `activeTab`: 사용자가 확장 프로그램을 누른 현재 탭에만 일시적으로 접근합니다.
- `scripting`: 조사 중인 쇼핑몰 화면의 보이는 텍스트와 공개 링크를 제한된 크기로 읽습니다.
- `storage`: 승인 상태와 중간 결과, PriceScan 작업 인증을 임시 보관합니다. 작업 인증은 결과 반영 전에 제거됩니다.
- `https://pricescan.d2blue.com/*`: 임시 결과를 PriceScan 웹앱에 전달합니다.

화면의 보이는 텍스트와 공개 링크는 PriceScan 서버 및 관리자가 설정한 AI 판독 서비스로 전송됩니다. 로그인 정보, 쿠키, 비밀번호, 폼 입력값, 스크린샷, 결제정보, 검색기록 전체는 읽거나 전송하지 않습니다.

## 개발자 로컬 설치

Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 이 폴더를 `압축해제된 확장 프로그램을 로드`로 선택합니다. 일반 사용자는 Chrome Web Store 버전을 설치합니다.

## 배포 패키지

```bash
./scripts/build-pricescan-collector-webstore.sh
```

생성된 ZIP만 Chrome Web Store에 업로드합니다. 데스크톱 앱은 확장 프로그램과 별도의 다운로드 상품으로 배포합니다.
