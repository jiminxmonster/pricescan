# Chrome Web Store 권한 설명

- `activeTab`: 사용자가 확장 프로그램 아이콘을 누른 현재 네이버 쇼핑 탭에만 일시적으로 접근하기 위해 필요합니다.
- `scripting`: 사용자가 보고 있는 현재 화면에서 상품명, 판매처, 가격, 배송비, 상품 링크를 구조화하기 위해 필요합니다.
- `storage`: 승인 단계, 선택 상품, 승인 시각과 중간 결과를 로컬에 보관하여 확장 프로그램 재시작 시 복원합니다. 전송 대기 데이터는 웹앱 반영 확인 후 지우며, 작업 요약/결과는 다음 수집 시작 시 대체됩니다.
- `sidePanel`: 자동 조사 진행 상태와 로그인·보안 확인·판독 불확실 등 사용자가 확인해야 할 상태를 고정 표시합니다.
- 선택적 쇼핑몰 호스트 권한: 네이버 쇼핑/스마트스토어/브랜드스토어, 다나와 검색/상품, 에누리, 쿠팡의 명시된 HTTPS 호스트에만 요청합니다. 최초 시작 버튼에서 선택한 쇼핑몰 권한을 한 번에 요청하고, 조사 중인 검색/상세 탭에만 DOM 리더를 주입합니다. 로그인/결제 URL은 거부합니다. 쿠키 API나 전체 방문기록 권한은 요청하지 않습니다.
- `https://pricescan.d2blue.com/*`: 확장 프로그램과 PriceScan 웹앱 사이에서 임시 결과를 전달하기 위해 필요합니다.

원격 코드는 사용하지 않으며 모든 실행 코드는 업로드된 확장 프로그램 패키지에 포함됩니다.
