PriceScan

Chrome Extension

개인정보처리방침

시행일 2026.09.03

PriceScan Collector는 사용자가 확장 프로그램 버튼을 눌렀을 때 현재 열려 있는 네이버 쇼핑 화면의 상품 가격 정보를 한 번만 읽어 PriceScan 가격 비교 서비스로 전달합니다.

수집하는 정보

  • 현재 화면에 표시된 상품명
  • 쇼핑몰 또는 판매처명
  • 상품 가격
  • 배송비
  • 상품 상세 링크
  • 수집 시각

수집하지 않는 정보

  • 쇼핑몰 아이디와 비밀번호
  • 쿠키와 인증정보
  • 결제·카드정보
  • 장바구니와 연락처
  • 개인 메시지
  • 전체 브라우징 기록
  • 사용자의 파일과 로컬 저장소 전체 내용

이용 목적

수집한 정보는 PriceScan 검색 결과, 쇼핑몰별 가격 비교, 최저가 그래프, 등록가·노출가 비교, 마진 검토 및 가격 모니터링 기능에만 사용합니다.

정보 전송과 공유

가격 정보는 사용자가 이용하는 PriceScan 서버로 전송될 수 있습니다. PriceScan은 이 정보를 제3자 광고 네트워크, 데이터 브로커 또는 별도 분석 업체에 판매하거나 제공하지 않습니다.

권한 사용

activeTab
사용자가 확장 프로그램 버튼을 누른 현재 네이버 쇼핑 탭에만 일시적으로 접근합니다.
scripting
현재 화면에 보이는 상품명, 판매처, 가격, 배송비와 상품 링크를 구조화합니다.
storage
PriceScan으로 전달할 한 번의 수집 결과를 기기에 임시 저장하고, 반영 확인 후 삭제합니다.
호스트 권한
PriceScan 웹앱과 수집 결과를 주고받는 데 사용합니다.

보관과 삭제

가격 정보는 가격 비교와 모니터링 제공에 필요한 기간 동안 저장될 수 있습니다. 삭제 또는 계정 관련 요청은 아래 이메일로 접수할 수 있습니다.
